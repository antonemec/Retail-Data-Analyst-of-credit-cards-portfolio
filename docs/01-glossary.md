# 01. Глосарій / Glossary

Терміни згруповано за темою. Формат: **Термін (EN)** — пояснення.

## Картка та продукт / Card and product

- **PAN / Номер картки** — 16–19 цифр. Перші 6–8 цифр — **BIN/IIN**: ідентифікатор емітента, платіжної системи та типу картки.
- **CVV2/CVC2** — 3-значний код на звороті для підтвердження автентичності онлайн-платежів. Зберігати його заборонено стандартом PCI DSS.
- **Магнітна смуга / Magnetic stripe, Chip (EMV), NFC** — носії даних картки: смуга найменш захищена, чип генерує одноразові криптограми, NFC — безконтактний канал.
- **Платіжна система / Payment scheme** — Visa, Mastercard, UnionPay, American Express. Визначає правила, ставки інтерчейнджу та арбітраж спорів.
- **Емітент / Issuer** — банк, що випустив картку. **Еквайєр / Acquirer** — банк, що обслуговує торговця та термінал.
- **Кредитний ліміт / Credit limit** — максимальна сума боргу, дозволена за карткою.
- **Баланс / Balance, Сальдо кредиту** — поточний борг клієнта. **Особисті кошти** — власні гроші клієнта на картці.
- **Пільговий період / Grace period** — період, протягом якого покупки не обтяжені відсотками за умови своєчасного погашення.
- **Мінімальний платіж / Minimum payment** — частка боргу (зазвичай 3–10%) + відсотки/комісії, що потрібно сплатити, щоб не перейти в прострочку.
- **Овердрафт / Overdraft** — кредит, що надається поверх залишку на дебетовій картці.

## Транзакції / Transactions

- **MCC (Merchant Category Code)** — 4-значний код категорії торговця (5411 — супермаркети, 5812 — ресторани, 5541 — АЗС). Основа аналізу споживчих витрат.
- **RRN (Retrieval Reference Number)** — унікальний номер операції для пошуку та розслідування спорів.
- **Код авторизації / Authorization code** — підтвердження, що емітент схвалив операцію.
- **Авторизація → кліринг → розрахунок / Authorization → clearing → settlement** — три етапи: резервування коштів, обмін фінансовими даними, фактичне переведення грошей.
- **Чарджбек / Chargeback** — повернення коштів за спором клієнта через платіжну систему.
- **Відмова / Decline** — відхилена операція. Причини: недостатньо коштів/ліміту, підозра на шахрайство, блокування, невірний PIN/CVV.
- **Інтерчейндж / Interchange** — комісія, що еквайєр платить емітенту з кожної операції; ключове джерело доходу емітента від транзакційних клієнтів.
- **Перевірка чека (ДПС)** — для фіскальних чеків в Україні: cabinet.tax.gov.ua/cashregs/check.

## Поведінка клієнта / Customer behaviour

- **Transactor** — повністю погашає борг у пільговий період; дохід банку — переважно інтерчейндж.
- **Revolver** — носить борг; дохід — відсотки, ризик вищий.
- **Утилізація / Utilization** — баланс / ліміт. Висока утилізація — сигнал ризику й потенційної потреби в збільшенні ліміту.
- **Активація / Activation** — перша транзакція після випуску. **Dormant** — картка без операцій N місяців.
- **Attrition / Churn** — відтік: закриття картки або тривала відсутність активності.
- **Cross-sell / Upsell** — додатковий продукт / перехід на вищий тариф.

## Ризик і якість портфеля / Risk and portfolio quality

- **DPD (Days Past Due)** — кількість днів прострочки. Кошики: 0, 1–30, 31–60, 61–90, 90+.
- **NPL (Non-Performing Loan)** — проблемна заборгованість; зазвичай DPD > 90 (визначення може відрізнятись).
- **Roll rate** — частка рахунків, що перейшли у гірший кошик прострочки за період.
- **Vintage** — когорта карток, відкритих в один період; відстежується за віком («місяці на балансі»).
- **Cost of Risk (CoR)** — вартість ризику: резерви за період / середній валовий портфель.
- **PD / LGD / EAD / ECL** — ймовірність дефолту / частка втрат / експозиція / очікувані збитки (ECL = PD × LGD × EAD).
- **МСФЗ 9 (IFRS 9) стадії 1–3** — класифікація за зростанням ризику: 12-місячний ECL на стадії 1, ECL за весь строк на стадіях 2–3.
- **Write-off / Списання** — виведення безнадійного боргу з балансу з подальшим стягненням.
- **Скоринг / Scorecard** — модель оцінки кредитоспроможності; **Gini/KS** — метрики її якості.

## Стягнення / Collections

- **Soft collection** — ранні нагадування (SMS, push, дзвінки) до ~30 DPD.
- **Hard collection** — інтенсивна робота, у т.ч. юридична, на пізніх кошиках.
- **Cure rate** — частка прострочених рахунків, що повернулись у 0 DPD.
- **Recovery rate** — частка боргу, повернена після дефолту (1 − LGD).
- **Promise to pay (PTP)** — обіцянка клієнта сплатити; **PTP kept rate** — частка виконаних обіцянок.

## Фінанси продукту / Product finance

- **APR / Процентна ставка** — річна ставка; **EAR** — ефективна з урахуванням капіталізації.
- **FTP (Funds Transfer Pricing)** — внутрішня ціна фондування.
- **NIM (Net Interest Margin)** — чиста процентна маржа.
- **ARPU** — середній дохід на клієнта/картку за період.
- **CLV / LTV** — приведена цінність клієнта за весь життєвий цикл.

## Що це дає аналітику / Why it matters

Ці терміни — основа для: виявлення шахрайства (аномалії в MCC, часі, географії), сегментації клієнтів (transactor/revolver, утилізація), прогнозування відтоку, оцінки ефективності кампаній і моніторингу якості портфеля.
