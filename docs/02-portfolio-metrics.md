# 02. Метрики портфеля / Portfolio metrics

Для кожної метрики: формула, як читати, типові помилки. Таблиці з прикладами SQL — у [03](03-sql-recipes.md). Спробувати формули можна в [калькуляторі](https://antonemec.github.io/analyst-html-tools/metrics-calculator.html).

## 1. Воронка та активність / Funnel and activity

| Метрика | Формула | Коментар |
|---|---|---|
| Approval rate | схвалені заявки / усі заявки | Дивіться разом з рівнем ризику, інакше легко «купити» схвалення ціною якості |
| Activation rate | картки з ≥1 транзакцією за N днів / випущені картки | Типово N = 30/60/90, фіксуйте вікно |
| Active rate | картки з транзакцією за місяць / відкриті картки | Визначення «активної» має бути єдиним у всьому банку |
| Dormant rate | картки без операцій N місяців / відкриті | Кандидати на реактивацію або закриття |
| Decline rate | відхилені операції / усі спроби | Розбивайте за причиною: ліміт, антифрод, технічна |

## 2. Використання ліміту / Limit usage

- **Utilization** = баланс / кредитний ліміт. Читати на рівні картки й портфеля (зважено на ліміт): `Σ balance / Σ limit`, а не середнє утилізацій.
- **Transactor share** = картки з `paid_amount ≥ statement_balance` / картки з балансом.
- **Revolver share** = картки з залишком боргу після пільгового періоду / картки з балансом.
- **Типова помилка:** рахувати утилізацію по закритих або заблокованих картках — вони спотворюють знаменник.

## 3. Дохід / Revenue

- **Interchange income** = обіг × ставка інтерчейнджу.
- **Interest income** = середній револьверний борг × APR (за днями користування).
- **Fee income** = комісії (обслуговування, зняття готівки, штрафи).
- **ARPU** = загальний дохід / середня кількість активних карток за період.
- **NIM** = (процентні доходи − процентні витрати) / середні активи, що приносять дохід.

## 4. Якість портфеля / Portfolio quality

- **DPD bucket share** = баланс (або кількість) у кошику / валовий портфель. Показуйте обидва варіанти: кількість рахунків і суму.
- **NPL ratio** = баланс DPD 90+ / валовий портфель.
- **Roll rate (A → B)** = рахунки в кошику A на початку, що опинились у B наприкінці / рахунки в A на початку.
- **Cure rate** = рахунки, що повернулись у 0 DPD / рахунки в кошику на початку.
- **Vintage curve** = для когорти за місяць відкриття — частка DPD30+ (або 90+) за віком картки (місяць на балансі). Криві когорт порівнюють на однакових відрізках віку.
- **Cost of Risk** = відрахування в резерви за рік / середній валовий портфель.

### Приклад інтерпретації roll rate

Якщо `1–30 → 31–60` = 40% і `31–60 → 61–90` = 65%, `61–90 → 90+` = 80%, то із 100 рахунків, що вперше зайшли у 1–30, до NPL дійдуть приблизно `100 × 0.40 × 0.65 × 0.80 ≈ 21`. Це швидка оцінка майбутніх NPL без складної моделі.

## 5. Очікувані збитки / Expected loss

`ECL = PD × LGD × EAD`

- **EAD** для карток = баланс + (ліміт − баланс) × CCF, де CCF — частка невикористаного ліміту, яку клієнт використає до дефолту.
- **PD** береться з скорингової моделі або емпіричних частот переходу в дефолт у вікні 12 місяців.
- **LGD** = 1 − recovery rate (з урахуванням дисконтування грошових потоків стягнення).

## 6. Відтік і цінність клієнта / Attrition and value

- **Attrition rate** = картки, закриті або неактивні N місяців / активні на початку періоду.
- **Retention (когортний)** = частка клієнтів когорти, що залишаються активними через k місяців.
- **CLV** = Σ (дохід_t − витрати_t − збитки_t) / (1 + r)^t за очікуваний життєвий цикл.

## Типові помилки аналітика / Common analyst mistakes

1. **Змішування стоків і потоків:** NPL — стан на дату, CoR — потік за період.
2. **Середнє середніх:** агрегуйте суми, потім діліть; не усереднюйте відсотки різних груп.
3. **Різні вікна спостереження** при порівнянні вінтажів.
4. **Виживання (survivorship bias):** не виключайте закриті картки з історичних розрахунків.
5. **Невідповідність дат:** транзакція за календарним місяцем vs виписка за платіжним циклом.
6. **Парадокс Сімпсона:** загальна метрика росте, а в кожному сегменті падає (змінилась структура портфеля).
7. **Відсутність контролю за якістю даних** — див. [чекліст](05-data-quality-checklist.md).

## Mini-dashboard: що має бути на екрані

- Ряд: видача, активація, обіг, баланс, утилізація.
- Якість: частка DPD по кошиках, roll rates, NPL, CoR.
- Дохід: інтерчейндж, відсотки, комісії, ARPU.
- Когорти: vintage curves по 6–12 останніх когортах.
- Алерти: відхилення метрик від 4-тижневого середнього більше ніж на 2σ.
