# 05. Чекліст якості даних / Data quality checklist

Перед будь-яким аналізом пройдіть список. Кожен пункт — коротке запитання «так/ні», плюс SQL для швидкої перевірки.

## Повнота / Completeness

- [ ] Є дані за всі очікувані періоди (немає «дірок» у календарі)?
  ```sql
  SELECT month, COUNT(*) FROM monthly_snapshots GROUP BY month ORDER BY month;
  ```
- [ ] Частка NULL у ключових полях прийнятна?
  ```sql
  SELECT SUM(credit_limit IS NULL)*1.0/COUNT(*) AS null_limit FROM cards;
  ```

## Унікальність / Uniqueness

- [ ] Первинні ключі унікальні?
  ```sql
  SELECT card_id, COUNT(*) FROM cards GROUP BY card_id HAVING COUNT(*) > 1;
  ```
- [ ] Один рядок знімка на пару (картка, місяць)?
  ```sql
  SELECT card_id, month, COUNT(*) FROM monthly_snapshots GROUP BY 1,2 HAVING COUNT(*) > 1;
  ```

## Узгодженість / Consistency

- [ ] Транзакції посилаються на існуючі картки (немає «сиріт»)?
  ```sql
  SELECT COUNT(*) FROM transactions t LEFT JOIN cards c ON c.card_id = t.card_id WHERE c.card_id IS NULL;
  ```
- [ ] Баланс не перевищує ліміт більше ніж допустимо?
  ```sql
  SELECT COUNT(*) FROM monthly_snapshots s JOIN cards c USING(card_id) WHERE s.balance > c.credit_limit * 1.05;
  ```
- [ ] DPD не від'ємний, не «стрибає» нелогічно (з 0 одразу у 120)?

## Валідність і діапазони / Validity

- [ ] Суми транзакцій > 0, дати в межах очікуваного діапазону?
- [ ] Допустимі значення довідників (status, channel, MCC)?
  ```sql
  SELECT DISTINCT status FROM transactions;
  ```

## Звірка / Reconciliation

- [ ] Сума балансів у знімку збігається з бухгалтерським обліком (допуск ≤ 0.1%)?
- [ ] Кількість карток збігається зі звітом бізнесу за ту саму дату?

## Часові аспекти / Timing

- [ ] Дата транзакції vs дата проведення vs дата виписки: яка використовується?
- [ ] Часові зони та перехід літнього/зимового часу?
- [ ] Затримки завантаження: чи остаточні останні дні?

## Безпека та приватність / Security and privacy

- [ ] Номери карток маскуються (показуємо BIN + останні 4)?
- [ ] CVV/PIN не зберігаються й не потрапляють у вибірки?
- [ ] Для навчальних і демо-даних — лише синтетичні дані.

## Документація / Documentation

- [ ] Визначення метрик записані (хто, коли, як рахує)?
- [ ] Відомі обмеження задокументовані поруч із результатом.

> Правило: якщо дані не пройшли перевірку — спершу повідомте власника даних, а потім будуйте висновки. Краще пізніше, ніж невірно.
